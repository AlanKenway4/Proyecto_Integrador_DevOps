\# Fase 1 - Proyecto Integrador DevOps



Durante la Fase 1 se realizó la preparación inicial del Proyecto Integrador DevOps utilizando Online Boutique como aplicación base.



Las actividades realizadas fueron:



\- Organización del trabajo mediante un tablero Kanban en Trello.

\- Clonación del repositorio oficial de Online Boutique.

\- Creación del repositorio propio Proyecto\_Integrador\_DevOps.

\- Configuración de los repositorios remotos origin y upstream.

\- Revisión de la estructura general de Online Boutique.

\- Preparación de Docker Desktop y Kubernetes.

\- Instalación y configuración de Skaffold.

\- Despliegue local de Online Boutique.

\- Definición y aplicación de GitHub Flow como estrategia de ramificación.



Para el control de cambios se utiliza la rama main como versión estable del proyecto y ramas feature para trabajar actividades específicas sin modificar directamente la rama principal.



Durante esta fase se creó la rama:



feature/fase-1-documentacion



En esta rama se documentan los cambios correspondientes a la Fase 1. Una vez terminados y comprobados, los cambios se integrarán nuevamente a main mediante un Pull Request.



La estrategia GitHub Flow fue seleccionada porque permite mantener la versión principal estable, trabajar cada cambio por separado y revisar las modificaciones antes de integrarlas al proyecto principal.
